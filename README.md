# 🛍️ My E-Commerce Store

A modern e-commerce website built with **Next.js** for selling beauty products, watches, mobile accessories, and lifestyle products.

## 🛠️ Tech Stack

* Next.js
* React
* Tailwind CSS
* Sanity CMS
* ASP.NET Core Web API
* SQL Server

## ✨ Features

* Product categories
* Product details
* Search
* Shopping cart
* Wishlist
* Responsive design
* Sanity CMS integration
* Admin dashboard *(planned)*
* Orders & payments *(planned)*

## 🚀 Getting Started

```bash
git clone https://github.com/tahir-1-cloud/my-ecommerce-store.git
cd my-ecommerce-store
npm install
npm run dev
```

Open **http://localhost:3000**
